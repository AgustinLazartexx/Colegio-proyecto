# Gestión Escolar Reina de la Esperanza

Aplicación web para la comunidad del Colegio Reina de la Esperanza, con acceso diferenciado para administración, docentes y estudiantes.

## Documentación

- [Documentación general del proyecto](./docs/DOCUMENTACION.md): alcance, módulos, arquitectura, base de datos, instalación, pruebas y capturas sugeridas.
- [Documentación en PDF](./docs/DOCUMENTACION-REINA-ESPERANZA.pdf): versión lista para compartir con la facultad.
- [Manual de usuario](./Manual%20de%20Usuario.pdf): guía de uso disponible.
- [Configuración de la demo pública](./DEMO-DEPLOYMENT.md): despliegue de demostración con Render y PostgreSQL.
- [Guía de desarrollo del backend](./proyectocolegio-backend/README.md): preparación de la base local, datos de prueba e inicio de la API.

## Estructura

```text
proyectoColegio-frontend/   Aplicación web React y Vite
proyectocolegio-backend/    API Express, acceso a datos y migraciones
docs/                       Documentación técnica y evidencias por completar
```

## Tecnologías principales

- Frontend: React, Vite, React Router y Axios.
- Backend: Node.js, Express y Sequelize.
- Datos: MariaDB para el entorno local; PostgreSQL para la demo pública.

Consulta la [documentación general](./docs/DOCUMENTACION.md) para los requisitos, comandos y detalles funcionales.
